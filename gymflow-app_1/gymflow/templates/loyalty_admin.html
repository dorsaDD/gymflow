Rule reference

Format: WHEN <condition> AND <condition> … THEN <action>. Put OR choices in brackets: (class.category == "yoga" OR class.category == "mobility"). A rule with no conditions is just THEN award_points(10). The first line WHEN event == "…" is optional and must match the trigger you pick.

Comparisons: == != > >= < <= IN [ … ]. Text values go in quotes.

Actions: award_points(10) · apply_discount(percent=5) · apply_discount(amount=10, target="membership") · grant_reward(3) (reward ID from the Rewards table, e.g. a free class credit). Discounts only work with the invoice_paid trigger and are capped at 50% of the invoice.

Examples

10 points for every attended class (trigger: class_attended)
THEN award_points(10)

50 bonus points at 8 classes in one month (trigger: class_attended, max 1 per member if you want it once)
WHEN member.attended_classes_month == 8 THEN award_points(50)

Discount on a second purchase within 30 days (trigger: invoice_paid)
WHEN member.purchase_count == 1 AND member.days_since_first_purchase <= 30
THEN apply_discount(percent=5)

Free class for ages 45–60, once per member (trigger: class_attended, max uses per member = 1)
WHEN member.age >= 45 AND member.age <= 60 THEN grant_reward(3)

Loyalty bonus after 1 year (trigger: member_activity, max uses per member = 1)
WHEN member.active_days >= 365 THEN award_points(100)

Gold members: 10% off membership renewals (trigger: invoice_paid)
WHEN member.tier == "Gold" THEN apply_discount(percent=10, target="membership")

Gold members: one free class every month (trigger: member_activity — checked once per month)
WHEN member.tier == "Gold" THEN grant_reward(3)

How conflicts work: points from every matching rule are added; only one discount applies to an invoice — the matching discount policy with the lowest priority number wins, and a member's own reserved reward is used only if no automatic discount applies. Location data and membership plans beyond invoice type are not stored by GymFlow, so there are no location facts.

Administrator point adjustment

Manual corrections change spendable balance, not lifetime qualifying points or tier. Every adjustment is recorded in the member ledger.
